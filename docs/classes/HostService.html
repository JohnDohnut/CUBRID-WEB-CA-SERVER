    Class HostService

    Service for managing host-related operations.

    Provides business logic for host management including retrieving host lists, adding new hosts, and validating host information. Handles host limits and duplicate detection.

    addHost

    • addHost(userId: string, hostInfo: AddHostRequest): Promise<User>

      Adds a new host to the user's host list.

      Validates host limits (max 50 hosts) and checks for duplicates before adding the new host. Uses atomic update to ensure data consistency.

      Parameters

      • userId: string

        The unique identifier of the user

      • hostInfo: AddHostRequest

        Host information without UID (will be generated)

      Returns Promise<User>

      The updated user object with the new host

      Throws

      When host limit is exceeded or duplicate host is found

      Throws

      When user is not found

      Example

      const newHost = await hostService.addHost("user123", {
        address: "192.168.1.100",
        port: 22,
        id: "server1",
        password: "encrypted_password"
      });
      console.log(newHost.host_list); // Contains the new host with generated UID
