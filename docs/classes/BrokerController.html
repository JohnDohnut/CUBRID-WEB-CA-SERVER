    Class BrokerController

    Controller for handling broker-related operations. Provides REST API endpoints for broker management operations including:

    • Get broker list for a specific host
    • Stop a broker
    • Start a broker
    • Restart a broker

    브로커 관련 작업을 처리하기 위한 컨트롤러입니다. 브로커의 시작, 중지, 재시작, 목록 조회를 위한 REST API 엔드포인트를 제공합니다.
